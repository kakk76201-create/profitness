# Fitness Up — оформление

Файл держит в одном месте всё, что относится к внешнему виду продукта за
пределами кода: две палитры, типографику, правила для иконок, фотографий
и иллюстраций, готовые промпты для их генерации.

Облик — спортивный. Светлая тема: белый и оранжевый. Тёмная тема: чёрный,
серый и тот же оранжевый. В обеих темах главный приём один — плотный
тёмный прямоугольник с белым заголовком в верхнем регистре и оранжевым
акцентом. Промпты и размеры фотографий — в `docs/IMAGES.md`.

## Палитра

Источник правды — `frontend/css/tokens.css`. Здесь дубль для дизайна и
для генерации картинок. Тему ставит `js/app.js` атрибутом `data-theme`
на `<html>`; по умолчанию берётся из Telegram, пользователь может
переключить вручную в профиле. Оранжевый один на обе темы — бренд от
темы не меняется.

## Контраст

Посчитан по формуле относительной яркости WCAG 2.x. Порог для обычного
текста 4.5:1, для крупного (от 24px или от 18.66px жирным) и для
нетекстовых элементов 3:1. Ухудшать эти пары при правках нельзя.

| Пара | Светлая | Тёмная | Порог | Вывод |
|---|---|---|---|---|
| Текст на фоне (`--text` / `--bg`) | 17.2:1 | 17.9:1 | 4.5 | проходит с запасом |
| Текст на карточке (`--text` / `--surface`) | 18.9:1 | 16.4:1 | 4.5 | проходит |
| Вторичный текст на карточке (`--muted` / `--surface`) | 6.0:1 | 7.1:1 | 4.5 | проходит |
| Вторичный текст на фоне (`--muted` / `--bg`) | 5.4:1 | 7.7:1 | 4.5 | проходит |
| Белый на оранжевом (`--on-accent` / `--accent`) | 3.4:1 | 3.4:1 | 3.0 крупный | **только крупный текст** |
| Белый на нажатом оранжевом (`--on-accent` / `--accent-press`) | 4.3:1 | 4.3:1 | 3.0 крупный | проходит |
| Оранжевый текст на карточке (`--accent-text` / `--surface`) | 5.2:1 | 7.7:1 | 4.5 | проходит |
| Оранжевый текст на мягкой подложке (`--accent-text` / `--accent-soft`) | 4.7:1 | 7.1:1 | 4.5 | проходит |
| Контур поля (`--border-strong` / `--surface`) | 3.4:1 | 3.6:1 | 3.0 нетекст | проходит |
| Белый в тёмном блоке (`--hero-text` / `--hero`) | 18.9:1 | 17.2:1 | 4.5 | проходит |
| Серый в тёмном блоке (`--hero-muted` / `--hero`) | 7.4:1 | 6.7:1 | 4.5 | проходит |
| Оранжевый в тёмном блоке (`--accent` / `--hero`) | 5.6:1 | 5.1:1 | 4.5 | проходит и мелким |
| Статусы на карточке (`--success`, `--warning`, `--danger`) | 5.0 / 5.0 / 4.8 | 10.4 / 10.8 / 6.5 | 4.5 | проходят |

Ключевое следствие. Белый на `#F5570B` даёт 3.4:1 — этого хватает только
для крупного текста. Поэтому подписи оранжевых кнопок набраны сжатым
шрифтом 20px/700 в верхнем регистре: они и по смыслу «команда», и по
правилам проходят. Мелкий оранжевый текст на белом этим цветом писать
нельзя — для него есть `--accent-text` (`#C2410C` на светлом, `#FF8A4C`
на тёмном). Оранжевый на тёмном блоке (`#F5570B` на `#111113`) даёт
5.6:1 и годится для любого кегля — это ещё одна причина держать акценты
в тёмных блоках.

## Типографика

Два шрифта, оба из Google Fonts.

| Роль | Шрифт | Начертания |
|---|---|---|
| Заголовки, крупные числа, кнопки, надзаголовки | Barlow Condensed (`--font-display`) | 600, 700 |
| Основной текст, интерфейс | Inter (`--font-body`) | 400, 500, 600 |

Сжатый гротеск даёт «табло стадиона» и позволяет набирать длинные
русские слова («ТРЕНИРОВКА», «ПОДДЕРЖАНИЕ») крупно, не ломая строку на
узком экране. Запасные: Roboto Condensed, Arial Narrow, затем `--font-body`.

Шкала кеглей из токенов:

| Токен | Кегль | Что |
|---|---|---|
| `--fs-display` | 44px | главные числа: остаток калорий, вес, таймер |
| `--fs-h1` | 30px | заголовок экрана, сжатый шрифт |
| `--fs-h2` | 22px | заголовок секции и карточки |
| `--fs-h3` | 17px | подзаголовок, крупная строка списка |
| `--fs-btn` | 20px | подпись кнопки, сжатый шрифт, верхний регистр |
| `--fs-body` | 15px | основной текст |
| `--fs-sm` | 13px | вторичный текст, подписи полей |
| `--fs-xs` | 12px | мета-информация |
| `--fs-2xs` | 11px | бейджи и надзаголовки в верхнем регистре |

Правила:

- `h1` и `h2` — капсом, интерлиньяж 1.05 (`--lh-tight`). `h3` — без
  капса: он стоит в карточках рядом с обычным текстом и капсом выглядел
  бы криком.
- Кнопки — Barlow Condensed 700, 20px, верхний регистр, разрядка `.04em`
  (`--ls-btn`).
- Надзаголовки (`.eyebrow`) — 11px, 700, верхний регистр, разрядка
  `.10em` (`--ls-eyebrow`): без разрядки капс «слипается».
- Крупные числа (`.num`) — табличные цифры (`tabular-nums`), чтобы
  значения не прыгали при пересчёте.
- Основной текст — Inter 15px, интерлиньяж 1.45.

## Иконки

Интерфейсные иконки живут в `frontend/js/icons.js` и рисуются кодом:
сетка 24×24, контур толщиной 2 (было 1.75 — тонкий штрих на 20 пикселях
выглядел вялым и «бумажным»), скруглённые концы, цвет наследуется от
текста. Заливка — только там, где без неё фигура не читается: треугольник
«плей», точки меню.

Исключение — нижняя панель (`#tabbar` в `index.html`): там иконки
сплошные силуэты (`fill="currentColor"`, без контура). Силуэт на 26
пикселях читается издалека и лучше держит оранжевую заливку активной
вкладки, чем контур.

Генерировать иконки нейросетью не нужно и вредно — на 24 пикселях
растровая картинка даёт рваные линии и разную толщину штриха, а SVG
масштабируется и перекрашивается сам. Новая иконка добавляется одной
строкой в объект `PATHS` того же файла.

## Тёмный блок с фотографией

Класс `.hero` (`frontend/css/style.css`) — плотный тёмный прямоугольник с
радиусом `--radius-xl` (22px), внутренним отступом 24px, белым заголовком
`h1`-кеглем капсом и серым `--hero-muted` для надзаголовка и меты. Сейчас
он стоит на экране «Сегодня» (блок тренировки дня и приглашение в
подписку) и на экране подписки.

Модификатор `.hero--img` кладёт фотографию фоном через переменную
`--hero-img`, а поверх неё — затемнение:

```
linear-gradient(180deg, rgba(0,0,0,.18) 0%, rgba(0,0,0,.74) 100%)
```

Сверху фото видно почти целиком, внизу — на четверть. Именно в нижней
трети стоят заголовок и кнопка, поэтому там фото должно оставаться
светлым и спокойным само по себе: затемнение доведёт его до нужной
плотности, а тёмное фото превратит в чёрное пятно. На одном экране —
один такой блок: его задача, чтобы главное действие находилось взглядом
мгновенно.

## Фотографии

Фото — основной визуальный материал приложения. Требования ко всем:

- Тёмные и контрастные: почти чёрный фон `#111113`, глубокие тени,
  жёсткий направленный свет, как в зале при одном прожекторе.
- Один тёплый оранжевый акцент `#F5570B` в кадре — подсветка, лента,
  деталь экипировки, гриф. Не заливать оранжевым весь кадр.
- Без текста, букв, цифр, логотипов, брендов и водяных знаков.
- Люди в движении: середина повторения, замах, шаг, наклон. Не позируют.
- Без стоковой улыбки в камеру. Лицо повёрнуто от объектива, взгляд на
  снаряд или в пол; допустимо кадрировать по плечи.
- Нижняя треть кадра свободна от деталей — под белый заголовок.
- Никакого «глянца»: без HDR-ореолов, без перенасыщенных цветов, без
  синего и фиолетового неона, без зелёного оттенка.

Список файлов, размеры и промпты — в `docs/IMAGES.md`.

## Логотип и аватар бота

Логотип — та же логика, что у иконок: простая геометрия, читается на
64 пикселях. Растровые варианты для BotFather (аватар 512×512) и для
магазинов стикеров генерировать можно, для интерфейса — только SVG.

```
Minimal sports app logo mark: a bold upward arrow merged with a dumbbell
silhouette, solid geometric shapes, rounded corners, no outlines. Two
colours only: warm orange #F5570B mark on a near-black #111113 background.
Centred, generous margin, works at 64px. No text, no letters, no gradients,
no glow, no 3D. Square 1:1.
```

Вариант для светлой подложки: тот же знак, `#F5570B` на `#FFFFFF`.

## Иллюстрации

Плоские иллюстрации остаются там, где фотография неуместна: аватар и
стикеры бота, картинки в сообщениях, состояние «нет данных для графика».
Для пустых состояний экранов и геройских блоков используются фото (см.
`docs/IMAGES.md`).

### Общие требования ко всем иллюстрациям

Дописывать к каждому промпту ниже:

```
Flat vector illustration, bold geometric shapes with slightly rounded
corners, no gradients, no drop shadows, no outlines thicker than 2px.
Strictly limited palette: near-black background #111113, main shapes
#FFFFFF, accent #F5570B, soft accent fill #2E1A10, muted details #A1A1AA.
No text, no letters, no numbers, no logos, no human faces. Energetic and
confident mood, dynamic diagonal composition, plenty of empty space, works
at 320px wide. Square 1:1.
```

Для светлой подложки палитру меняем на: фон `#F4F4F5`, фигуры `#FFFFFF`
с волосяным контуром `#E4E4E7`, акцент `#F5570B`, мягкая заливка
`#FFF1E8`, тёмные детали `#111113`, приглушённые `#63636B`.

### 1. Пустой дневник питания

```
An empty plate seen from directly above, with a fork and knife placed on
both sides at a slight diagonal. A single orange accent ring around the
plate rim. The composition reads as "ready for the first meal", not as
"nothing here".
```

### 2. Программа тренировок ещё не собрана

```
A blank weekly planner board with seven empty slots in a row, and one
dumbbell with orange end plates resting in front of it, as if waiting to
be placed into a slot. Simple, no clutter.
```

### 3. Экран подписки, главная картинка

```
Three stacked cards fanned out slightly: the front one shows an abstract
rising orange line chart, the middle one an abstract dumbbell silhouette,
the back one an abstract plate. They read as one connected product. Wide
16:9 instead of square.
```

### 4. Первая тренировка завершена

```
A single dumbbell resting on the floor with a hard circular orange glow
behind it, and three small white check marks floating above in an arc.
Celebratory but restrained, no confetti, no fireworks.
```

### 5. Приветствие в онбординге

```
A simple standing figure without facial features, seen from the side in an
athletic ready stance, next to a large circular orange progress ring that
is about one third filled. The figure and the ring are the same height.
Reads as "we start together".
```

### 6. Нет данных для графика прогресса

```
An empty coordinate grid with a faint horizontal baseline and a single
small orange dot placed at the very start of it. Nothing else. Reads as
"the first point is yours to add".
```

## Тексты для BotFather

Имя бота, описание, короткое описание, подпись кнопки меню и приветствие
на `/start` — в истории задач проекта. Ключевое: подпись кнопки меню
короткая («Открыть»), описание до 512 символов, короткое описание до 120.
Картинка для стартового сообщения (16:9) и обложка пейволла (4:3) —
промпты в `docs/IMAGES.md`.
